---
description: Start, update or close the session journal for the current branch
argument-hint: start|note|pause|finish
---

Use the `raj` skill for the action: $ARGUMENTS

- `start` — create a journal for the current branch
- `note` — update `## Now` and append a `✎` line to the timeline
- `pause` — same as `note`, before a deliberate stop
- `finish` — summarize into the PR, delete the file, close the journal

No argument — show the current state of the journal.
